Integrations FAQ

Last reviewed: 2025-11-20

Which integrations are available on each plan?

Slack and Google Drive integrations are available on all plans, including Free. GitHub and Jira integrations require Pro or Enterprise. Custom webhooks are available on Pro (up to 5 per workspace) and Enterprise (unlimited).

Who can install an integration?

Workspace Owners and Admins can install integrations. Members can connect their personal Slack account for notifications once the workspace integration is installed. Guests cannot install or use integrations.

Slack notifications stopped arriving. What should I check?

  1. Confirm the workspace is not suspended; integrations stop syncing in suspended workspaces.
  2. Check that the Slack app has not been removed from the Slack channel.
  3. Reconnect the integration under Settings → Integrations → Slack. Slack tokens expire if the installing admin's Slack account is deactivated.

GitHub pull requests are not linking to tasks.

Pull requests link to tasks when the PR title or branch name contains the task key, for example TL-1423. Links are created within 2 minutes. If the workspace downgraded to Free, the GitHub integration is disabled and existing links stay visible but stop updating.

Webhook deliveries are failing.

Tasklane retries failed webhook deliveries up to 5 times with exponential backoff over about 30 minutes. After 5 failures, the delivery is marked Failed. If more than 100 deliveries to the same endpoint fail within 24 hours, the webhook is disabled automatically and the workspace Owner receives an email. Your endpoint must respond with a 2xx status within 10 seconds.
